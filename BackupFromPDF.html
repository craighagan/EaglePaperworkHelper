Make a Backup File From a Workbook PDF

Already filled in the official workbook PDF? Bring those answers into the workbook pages.

This page never sends your answers anywhere. The backup file it makes holds personal details, so it goes wherever you copy or share it.

Step 1. Choose your filled workbook PDF

Choose the Eagle Scout Service Project Workbook No. 2023a PDF with your answers typed in. It must still have its fillable boxes (a copy printed to PDF does not).

Use your backup file when you have one. It has everything, including signed pages and links. This page is for when all you have is a filled PDF. A submission copy can’t be read here. (“Open backup file” is a button on the workbook pages, not on this page.)

Step 2. Save your answers

A PDF can’t hold signed pages, attachments, or links. If you added scans of signed pages, permits, or links in a workbook page, they are not in the backup file saved here. The “Open in” buttons keep the ones already in that workbook page’s draft (and ask first if the name on the PDF is different). If you open the saved backup file with “Open backup file” instead, the workbook page lists any signed pages or links that are on the page now and not in the file, and removes them only if you say yes.

The “Open in” buttons work when this page and the workbook pages share saved drafts (Chrome or Edge, or the same website). If the workbook page opens empty, use “Save backup file” and then “Open backup file” there.

Keep the backup file somewhere safe, such as Google Drive or Dropbox. Then read through every page of the workbook. Signatures are not part of the PDF’s boxes, so get them on paper or as your council directs.
