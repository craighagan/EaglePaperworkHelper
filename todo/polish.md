# Small polish

**Status:** ready to do. Minor items left over from the reviews. None blocks use.

1. **"Last backup file: never" after switching workbooks.** When the Guided workbook starts from the Classic workbook's draft (it does this when it has no draft of its own), its status line says "Last backup file: never", even if a backup file was saved from the Classic workbook. Fix: when loading from `classicStore` in `lib/guided-workbook.js`, carry over its `_backup` time. Add a browser test.
2. **Acrobat mention.** The fill report suggests opening the PDF in Adobe Acrobat Reader, which hasn't been verified yet. Resolve together with [browser-testing.md](browser-testing.md).
3. **Backup help is hard to find after Set Up.** "How to keep your work safe" sits at the bottom of each workbook page and is open only on Set Up. Fix: add a "How do I keep this safe?" link next to the top Save button that opens it. Do this if a real Scout or parent can't find where to save their work. Also say "tap" on phones, and warn that a school Google account may not be private (`lib/workbook-common.js`, `backupHelp`).
4. **Esc from inside a box doesn't close an open tip.** The keydown listener on the tip panel never fires because the panel has no focusable content (`lib/workbook-common.js`, `makeTip`). Close on Esc from the input, or remove the dead listener.
5. **Tip state on erase and redraw.** `openTips` isn't cleared when the Scout erases their answers, and the backup help panel closes on redraw. Clear `openTips` on erase and keep the panel open across redraws.
6. **Share failure message.** `shareBackup` uses `alert()` and says "Downloads folder", which isn't true in every browser (iOS asks where to save). Use an on-page message. The success path also marks the backup as done when the share sheet closes, which doesn't prove the file arrived.
7. **Example variety.** Most tip examples are gardens, beds and lumber. Add examples for other project types (signs, collections, events, digital work).
8. **Tip wording.** Rewrite weak tips: helperCount, report.startDate, collected, leftoverMaterials, materials, costs (needs an example), thanks. Add "significant" back to report.changes and report.materialsUsed. Point report.description away from the planning box. Optional gaps: fundraising approval timing (two weeks), the five proposal tests, the Navigating sheet, Youth Protection and two-deep.
9. **Rotate a scan.** A sideways photo with no orientation tag becomes a sideways page in the submission copy. Add a "Rotate" button per page that redraws the JPEG turned 90° (`lib/attachments.js`, `attachmentsSection` in `lib/workbook-common.js`).
10. **Ask the browser to keep scans.** Call `navigator.storage.persist()` after the first scan is added, so the browser is less likely to evict IndexedDB under storage pressure (Safari evicts on its own schedule). The backup file stays the real save either way.
11. **Check the submission copy in more viewers in the tests.** Run Ghostscript (`gs -sDEVICE=nullpage`) and the PDFKit check on the submission copy when installed. A reviewer checked qpdf, Poppler, Ghostscript, MuPDF, pdf.js, and PDFKit by hand.
12. **Warn when saving the draft fails on flush.** `store.flush` fails silently when localStorage is full; make it report `'failed'` like `save` does, so the "could not save your draft" warning shows (`lib/workbook-common.js`, `createStore`).
13. **Ignore `*.webp`** in `.gitignore` along with the other picture types.
14. **More tests for the Signed Pages tab.** Add a CMYK picture test, browser tests for "Open backup file" and "Remove" being blocked while a file is read, and lead the Fundraising Page A card with "Only if you need a fundraising application." on its own line.
