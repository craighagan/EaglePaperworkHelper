# Small polish

**Status:** ready to do. Minor items left over from the reviews. None blocks use.

1. **"Last backup file: never" after switching workbooks.** When the Guided workbook starts from the Classic workbook's draft (it does this when it has no draft of its own), its status line says "Last backup file: never", even if a backup file was saved from the Classic workbook. Fix: when loading from `classicStore` in `lib/guided-workbook.js`, carry over its `_backup` time. Add a browser test.
2. **Acrobat mention.** The fill report suggests opening the PDF in Adobe Acrobat Reader, which hasn't been verified yet. Resolve together with [browser-testing.md](browser-testing.md).
3. **Backup help is hard to find after Set Up.** "How to keep your work safe" sits at the bottom of each workbook page and is open only on Set Up. Fix: add a "How do I keep this safe?" link next to the top Save button that opens it. Do this if a real Scout or parent can't find where to save their work. Also say "tap" on phones, and warn that a school Google account may not be private (`lib/workbook-common.js`, `backupHelp`).
4. **Esc from inside a box doesn't close an open tip.** The keydown listener on the tip panel never fires because the panel has no focusable content (`lib/workbook-common.js`, `makeTip`). Close on Esc from the input, or remove the dead listener.
5. **Tip state on erase and redraw.** `openTips` isn't cleared when the Scout erases their answers, and the backup help panel closes on redraw. Clear `openTips` on erase and keep the panel open across redraws.
6. **Share failure message.** `shareBackup` uses `alert()` and says "Downloads folder", which isn't true in every browser (iOS asks where to save). Use an on-page message. The success path also marks the backup as done when the share sheet closes, which doesn't prove the file arrived.
7. **Example variety.** Most tip examples are gardens, beds and lumber. Add examples for other project types (signs, collections, events, digital work).
8. **Tip wording.** Rewrite weak tips: helperCount, report.startDate, collected, materials, costs (needs an example), thanks. Add "significant" back to report.changes and report.materialsUsed. Point report.description away from the planning box. Optional gaps: fundraising approval timing (two weeks), the five proposal tests, the Navigating sheet, Youth Protection and two-deep.
9. **Rotate a scan.** A sideways photo with no orientation tag becomes a sideways page in the submission copy. Add a "Rotate" button per page that redraws the JPEG turned 90° (`lib/attachments.js`, `attachmentsSection` in `lib/workbook-common.js`).
10. **Ask the browser to keep scans.** Call `navigator.storage.persist()` after the first scan is added, so the browser is less likely to evict IndexedDB under storage pressure (Safari evicts on its own schedule). The backup file stays the real save either way.
11. **Check the submission copy in more viewers in the tests.** Run Ghostscript (`gs -sDEVICE=nullpage`) and the PDFKit check on the submission copy when installed. A reviewer checked qpdf, Poppler, Ghostscript, MuPDF, pdf.js, and PDFKit by hand.
12. **(Done in the scan fixes: `flush` now reports saved or failed.) Warn when saving the draft fails on flush.** `store.flush` fails silently when localStorage is full; make it report `'failed'` like `save` does, so the "could not save your draft" warning shows (`lib/workbook-common.js`, `createStore`).
13. **Ignore `*.webp`** in `.gitignore` along with the other picture types.
14. **More tests for the Signed Pages tab.** Add a CMYK picture test, browser tests for "Open backup file" and "Remove" being blocked while a file is read, and lead the Fundraising Page A card with "Only if you need a fundraising application." on its own line.
15. **Reading a PDF back: clearer messages.** A truncated filled PDF says "no answers typed in yet" (pdf.js rebuilds the blank first revision); say it may be damaged. Warn when a date typed in the PDF can't be understood (`June 1`, `6/1/25`, `2/30/2025`): it is kept as typed and the workbook shows a hint, but the read report says "No problems". Mention when a typed grand total differs from its rows (it is recomputed).

## Left over from the repo-wide scan (all MINOR; found and verified by reviewers)

16. **Attachments redraw closes an opened help section and drops focus** in a link or label box while a picture is added (`draw()` in `attachmentsSection`, `lib/workbook-common.js`). Keep `details.open` in a Set, like `openTips`.
17. **Two quick file choices can leave stale results** on the Fill page and Backup-from-PDF: choose file A (slow), then B; if A finishes last, its bytes win while the label says B. Add a request counter and ignore results unless they are the latest (`lib/fill-page.js`, `lib/backup-from-pdf-page.js`).
18. **Erase or open-backup during a multi-page add** can leave scanned pictures in IndexedDB: re-check the owner inside the page loop and `await clearAll()` (`addFiles`, `confirmErase`).
19. **Silent drops in `sanitize`** (`lib/attachments.js`): pages past 40 and oversized pictures vanish without telling the Scout. Count them and say so on the Signed Pages tab and the Fill page.
20. **Partial multi-file add:** if file 2 fails after file 1 was added, the message names only the failure. Say that file 1 was added.
21. **Empty `catch {}` blocks that can mislead:** erase says "erased" even if `removeItem` or the IndexedDB clear failed (`workbook-common.js`, `attachments.js`), which matters on a shared computer; an unreadable draft is overwritten without a prompt on "Open in the workbook" (`backup-from-pdf-page.js`) and is silently not offered on the Fill page (`fill-page.js`).
22. **A damaged draft cannot be recovered from the page.** `<key>_corrupt` holds the text but nothing offers it back. Add a "Download the unreadable copy" link next to the notice.
23. **Draft fallback is silent:** a Guided draft missing `candidate` or `proposal` loads as blank and Guided then uses the Classic draft; the first keystroke overwrites the Guided key. Say which draft was opened.
24. **Comma-decimal amounts in single boxes** (`report.spent` "12,50", collected, to be raised, how much) get no "not a plain number" note, unlike list rows.
25. **Deploy script, smaller things:** the header check uses `curl` without `-L` and only looks at the home page, not `lib/*.js`; `--target host:./` passes the "top of the account" guard; the README it copies links to `AGENTS.md`, which is not copied.
26. **`tools/vendor-pdfjs.cjs`** writes `pdf.js` and `pdf.worker.js` before the licence and wasm hashes are verified, so a later failure leaves a mixed vendor folder. Verify everything, then write.
27. **Dead or duplicated code:** `enc` and `void enc` in `writePdf` (`attachments.js`), unused exports `rowTotal` and `OFFICIAL_PAGE_URL`, `looksLikeWorkbook` copied into `fill-page.js`, the misleading name `SIGNATURE_FIELDS`, the backup filename stamp copied in `backup-from-pdf-page.js`, and `OFFICIAL_PDF_URL` defined in both `workbook-common.js` and `official-pdf.js` (a test now pins them equal).
28. **Hand-copied values:** the "at least two weeks" fundraising rule is worded three ways (`attachments.js`, `guided-workbook.js`, `classic-workbook.js`), and `costTable` row limits are numbers in the page scripts instead of read from `COST_TABLES`.
29. **Small differences between the workbooks:** Guided sets `inputmode: 'numeric'` on PID, ZIP, and helper count; Classic does not. The tab name `'Set Up'` / `'Contact Info'` is typed in two places instead of read from `TABS[0]`.
30. **Text-fit estimate:** `textWidth` counts emoji and CJK as half their real width, and `wrappedLines` can split a surrogate pair.
